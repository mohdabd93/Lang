# تعلّم: يونانية وإنجليزي

تطبيق ويب لتعلّم اليونانية (للتحضير لاختبار الجنسية والتفاهم بالحياة اليومية) وتقوية الإنجليزي.

**يشتغل بدون أي اشتراك ولا مفتاح ولا سيرفر خاص.** كل المحتوى مكتوب جاهزًا داخل التطبيق. وإذا حبيت لاحقًا، فيك تضيف ذكاء اصطناعي (اختياري).

## حجم المحتوى الحالي
- **اليونانية**: 38 قصة (A1: 11، A2: 11، B1: 16، منها 6 نصوص طويلة بين 135 و156 كلمة).
- **الإنجليزية**: 37 قصة (A1: 7، A2: 9، B1: 14، B2: 7، والـ B1 فيها 5 نصوص طويلة بين 143 و165 كلمة).
- **أسئلة تحديد المستوى**: 12 لكل مستوى بكل لغة.
- **أسئلة الجنسية**: 69 سؤالًا (تاريخ 19، جغرافيا 12، دولة ومؤسسات 13، ثقافة 13، أعياد وتقاليد 12).
- **حوارات**: 8 يونانية و4 إنجليزية، و54 جملة بقاء.
- القصص تُقدَّم جديدة أولًا، ولا تتكرر حتى تنتهي كل قصص مستواك.

> ⚠️ **الامتحان التجريبي تقدير من التطبيق وليس نتيجة رسمية**، وشكل الامتحان الحقيقي وشروط النجاح ممكن تختلف.
> ⚠️ **أسئلة الجنسية للتدريب فقط**: ليست بنك الأسئلة الرسمي، وكتبتها من معلومات عامة معروفة. اعتمد دائمًا على مادة الدراسة الرسمية من الجهة المختصة.
> ⚠️ **راجع المحتوى اليوناني** مع معلّم أو متحدّث، خصوصًا الجمل العملية، قبل ما تعتمد عليه بموقف رسمي. النطق بالحروف العربية تقريبي.
> تمرين الاستماع يحتاج صوتًا للغة على جهازك (يوناني/إنجليزي). على Windows: الإعدادات ← الوقت واللغة ← اللغة، أضف اليونانية ونزّل حزمة الكلام. التطبيق يحذّرك إذا ما لقي صوتًا.
> قسم جمل البقاء للغة فقط وليس نصيحة قانونية.

## التشغيل (بدون .NET)
المجلد `wwwroot` هو التطبيق كله: ملفات HTML وJS ثابتة.

**تجربة محلية سريعة**
```
cd wwwroot
python -m http.server 8000
```
وافتح `http://localhost:8000`. أو افتح `index.html` من أي سيرفر ملفات.

## النشر على IIS (نسخ ملفات فقط)
1. انسخ **محتوى** مجلد `wwwroot` (وليس المجلد نفسه) إلى مجلد الموقع، مثل `C:\inetpub\lang`.
2. في IIS Manager: أنشئ **Site** أو **Application** يشير لهذا المجلد.
3. تأكد إن **Default Document** فيه `index.html` (هو موجود افتراضيًا).
4. افتح الموقع. انتهينا. لا تحتاج Hosting Bundle ولا Application Pool خاص ولا أي إعداد.

بياناتك (تقدّمك، كلماتك) محفوظة بمتصفحك. من **الإعدادات** تقدر تنزّل نسخة احتياطية وتستوردها بجهاز ثاني.

## تعديل المحتوى
كل المحتوى بملفات نصية:
```
wwwroot/content/el.js       اليونانية: أسئلة المستوى، القصص، تمارين الكتابة
wwwroot/content/el-more.js  المزيد من المحتوى اليوناني (يُضاف إلى el.js)
wwwroot/content/el-long.js  نصوص يونانية طويلة (B1)
wwwroot/content/en.js       الإنجليزية: نفس الشي
wwwroot/content/en-more.js  المزيد من المحتوى الإنجليزي
wwwroot/content/en-long.js  نصوص إنجليزية طويلة (B1)
wwwroot/content/common.js   أسئلة الجنسية + جمل البقاء
wwwroot/content/common-more.js  المزيد من أسئلة الجنسية
wwwroot/content/dialogues.js الحوارات العملية (وهي أيضًا مصدر جمل تمرين الاستماع)
```
في كل سؤال **الخيار الأول هو الصحيح**، والتطبيق بيخلط الأماكن تلقائيًا. انسخ قصة موجودة وعدّل عليها لإضافة قصة جديدة، ويفضّل أن يكون `id` فريدًا.

## اختياري: ذكاء اصطناعي (Claude API)
إذا حبيت قصصًا وتصحيح كتابة بلا حدود، فيه باك إند ASP.NET Core جاهز بالمشروع. **لا حاجة له الآن.** ما بيشتغل إلا إذا حطيت مفتاحًا.

- يحتاج **مفتاح API** من console.anthropic.com (منتج منفصل عن اشتراك Claude Pro، وبفوترة حسب الاستخدام).
- شغّله بـ `dotnet run`، وأضف المفتاح كمتغير بيئة `ANTHROPIC_API_KEY`.
- لـ IIS: `dotnet publish -c Release -o publish`، ونصّب **.NET 8 Hosting Bundle** على السيرفر، وحط المفتاح بملف `appsettings.Production.json` داخل مجلد الموقع:
  ```json
  { "Anthropic": { "ApiKey": "sk-ant-..." }, "AppPasscode": "رمز-سري" }
  ```
- `AppPasscode`: مهم إذا الموقع على الإنترنت، حتى ما حدا يستهلك رصيدك. وفيه حدّ 60 طلب بالدقيقة لكل IP.
- التطبيق بيكتشف تلقائيًا: إذا السيرفر عنده مفتاح بيستخدم الـ AI، وإلا بيستخدم المحتوى الجاهز.

## أفكار للمرحلة الجاية
- المزيد من القصص والحوارات لكل مستوى.
- المزيد من الحوارات والقصص، فالامتحان يعيد استخدام نفس البنك.
- تحويل مادة الدراسة الرسمية للجنسية إلى أسئلة تدريب دقيقة.
