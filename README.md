# تعلّم: يونانية وإنجليزي مع الذكاء الاصطناعي

تطبيق ويب بسيط لتعلّم اليونانية (للتحضير لاختبار الجنسية) وتقوية الإنجليزي.

- **الواجهة**: HTML وCSS وJavaScript عادي. ما في React ولا npm ولا build.
- **الباك إند**: ASP.NET Core صغير (ملف واحد تقريبًا). وظيفته الوحيدة إنه يحمي مفتاح Claude API ويكلّم النموذج.
- **التخزين**: تقدّمك محفوظ في متصفحك (localStorage)، وفي الإعدادات زر لنسخة احتياطية.

## شو فيه
| الميزة | الوصف |
|---|---|
| امتحان مستوى تكيّفي | 10 أسئلة، بتصعب وتسهل حسب إجاباتك، وبتطلع مستواك (A1 إلى B2). |
| جلسة اليوم | مراجعة كلمات، ثم قصة بمستواك فيها كلماتك الضعيفة، ثم 4 أسئلة، ثم تمرين كتابة بتصحيح AI. |
| صعوبة تلقائية | معدّل آخر جلستين فأكثر 85% أو أعلى يرفع المستوى. أقل من 55% يخفّضه. |
| اضغط على أي كلمة | شرح فوري بالعربي مع تصريف ومثال، وزر "أضف للمراجعة". |
| مراجعة كلمات (SRS) | الكلمات اللي بتنساها بترجع أكثر. |
| اختبار الجنسية | أسئلة تاريخ وثقافة ومؤسسات بيونانية بسيطة مع شرح بالعربي. |

> ⚠️ أسئلة الجنسية مولّدة بالـ AI للتدرّب على الأسلوب فقط. اعتمد دائمًا على مادة الدراسة الرسمية.

## تشغيل محلي
```
dotnet run
```
افتح `http://localhost:5000` (أو الرابط اللي بيظهر بالشاشة).

**بدون مفتاح** التطبيق بيشتغل بـ **وضع تجريبي** فيه محتوى جاهز مسبقًا. أضف المفتاح عشان يشتغل الـ AI فعليًا:
```
set ANTHROPIC_API_KEY=sk-ant-...        (Windows)
export ANTHROPIC_API_KEY=sk-ant-...     (Linux/Mac)
```

## النشر على IIS (خطوة بخطوة)

**مرة وحدة على السيرفر**
1. نصّب **.NET 8 Hosting Bundle** (من صفحة تحميل .NET 8 الرسمية، اختر *Hosting Bundle*)، ثم أعد تشغيل IIS: `iisreset`.

**على جهازك (فيه .NET 8 SDK)**
```
dotnet publish -c Release -o publish
```
هاد بينتج مجلد `publish` فيه كل شي، بما فيه `web.config`.

**على السيرفر**
1. انسخ محتوى مجلد `publish` إلى مجلد الموقع، مثلًا `C:\inetpub\lang`.
2. في IIS Manager: أنشئ **Application Pool** جديد وخلّي **.NET CLR version = No Managed Code**.
3. أنشئ **Site** يشير إلى المجلد وإلى هذا الـ Pool.
4. أعطِ حساب الـ Pool (`IIS AppPool\اسم_الـPool`) صلاحية **Read** على المجلد.
5. أنشئ ملف `appsettings.Production.json` **داخل مجلد الموقع على السيرفر** (لا ترفعه على Git):
   ```json
   {
     "Anthropic": { "ApiKey": "sk-ant-..." },
     "AppPasscode": "رمز-سري-اختياري"
   }
   ```
6. أعد تشغيل الـ Pool (Recycle) وافتح الموقع.

**ملاحظات**
- **`AppPasscode`**: إذا الموقع على الإنترنت، حطّ رمزًا. التطبيق بيطلبه مرة وحدة من كل جهاز، وبدونه أي شخص بيعرف الرابط بيقدر يستهلك رصيد الـ API.
- فيه حدّ **60 طلب AI بالدقيقة** لكل IP.
- أي تعديل لاحق: انشر مجددًا وانسخ فوق الملفات القديمة (ما بتلمس `appsettings.Production.json`)، أو أوقف الـ Pool قبل النسخ إذا الملفات مقفولة.
- إذا طلع خطأ 500.19 أو 502.5: غالبًا الـ Hosting Bundle غير منصّب أو ما اتعمل `iisreset` بعده. فعّل `stdoutLogEnabled="true"` بملف `web.config` وأنشئ مجلد `logs` لقراءة السبب.
- **النموذج**: افتراضيًا `claude-haiku-4-5-20251001` (سريع ورخيص). لتغييره حط `"Anthropic": { "Model": "..." }` في نفس الملف.

## هيكل المشروع
```
Program.cs        الإعداد، محدد الطلبات، رمز الدخول، مسارات /api/*
AiService.cs      الأوامر (prompts) للنموذج، التحقق من الرد، خلط أماكن الإجابات
DemoData.cs       المحتوى التجريبي بدون مفتاح
wwwroot/          الواجهة: index.html و style.css و app.js
```

- حساب مستخدم وتخزين بالسيرفر عشان التقدّم يتزامن بين الأجهزة.
